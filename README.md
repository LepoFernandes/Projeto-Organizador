![Preview do Projeto](src/img/mockup/imagem_6_6.png) <!-- opcional: coloca print da tela -->

## 🚀 Sobre o projeto

Esse foi um dos meus primeiros projetos, feito para praticar **HTML, CSS e JavaScript**.
A ideia foi criar um **organizador simples de tarefas**, permitindo:

* Adicionar novas tarefas
* Editar tarefas existentes
* Excluir tarefas
* Marcar como concluídas

Apesar de ser um projeto iniciante, já trouxe bastante aprendizado sobre **manipulação do DOM** e **interatividade com JavaScript**.

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Projeto-Organizador.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Organizador
   ```
3. Abra o arquivo `index.html` no navegador.
